# # SA-MP / open.mp Roleplay Gamemode (Base / Polosan)

Halo! Ini adalah gamemode polosan (base) untuk server Roleplay yang dibangun di atas platform SA-MP / open.mp. Gamemode ini dirancang sebagai fondasi awal yang ringan dan terstruktur. Isinya belum sepenuhnya jadi (work in progress), sangat cocok untuk dikembangkan lebih lanjut atau dijadikan bahan pembelajaran.

## Fitur Utama

Saat ini, gamemode sudah dilengkapi dengan beberapa fitur dasar yang krusial untuk server Roleplay:

*   **Sistem Login & Register:** Sistem autentikasi pemain (terinspirasi/referensi dari basis Xyornite).
*   **Sistem Level & EXP:** Mekanisme perkembangan karakter pemain berdasarkan akumulasi poin pengalaman.
*   **Dealer Kendaraan:** Sistem tempat pembelian kendaraan bagi para pemain di dalam game.
*   **Kendaraan Pribadi (Private Vehicle):** Sistem kepemilikan kendaraan individu yang tersimpan secara dinamis.
*   **Kebutuhan Karakter (Hunger & Energy):** Fitur survival dasar yang mengatur rasa lapar dan stamina/energi karakter pemain.

## Status Proyek

*   **Status:** Belum sepenuhnya jadi (Development / Work in Progress).
*   **Tujuan:** Menyediakan base script yang bersih, optimal, dan mudah dikembangkan oleh scripter lain.

## Credits & Dependencies

Terima kasih kepada para kreator *library* dan *plugin* hebat berikut yang digunakan sebagai pilar utama dalam pengembangan gamemode ini:

*   **MySQL** – Untuk manajemen dan penyimpanan database secara dinamis dan efisien.
*   **YSI (Y-Less Incognito)** – Menyediakan struktur *framework* tingkat lanjut untuk optimalisasi script.
*   **sscanf2** – Untuk *parsing* string dan argumen perintah secara cepat.
*   **bcrypt** – Menangani enkripsi password akun pemain demi keamanan data yang maksimal.
*   **izcmd** – *Command processor* super cepat untuk menangani semua perintah (*commands*) dalam server.
